# Images du dépôt

Déposer une image ici (interface web de GitHub : « Add file › Upload files ») la rend disponible dans le Factsheet creator
au prochain déploiement (~1 min). Le fichier `index.json` est régénéré tout seul à chaque déploiement : ne pas le modifier.

- `logos/<famille>/` : une famille de logos = un dossier. Le nom du fichier contient la version : `default`, `mono`, `white` ou `neg`/`negative` (ex. `pec_neg_h_rgb_en.svg`) ; un nom exact (`default.png`) l'emporte.
- `header/<dossier>/` : images du header (132 px de haut), rangées par sous-dossier.
- `others/` (sous-dossiers possibles) : images du corps de la factsheet.

Noms en minuscules, sans accent ni espace. Formats : png, jpg, svg, webp, gif.
