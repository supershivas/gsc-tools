Batch Logo Export

Script Illustrator qui exporte les artboards d'un fichier de logos dans toutes les langues, en une seule opération : EPS et PDF pour un document CMJN, PNG et SVG pour un document RVB.

Télécharger le script batch_logo_export.jsx · v10 · Illustrator · interface FR / EN

01Installation

  1. Télécharger le fichierEnregistre batch_logo_export.jsx où tu veux (le Bureau convient).
  2. Lancer sans installerDans Illustrator : Fichier › Scripts › Autre script… puis choisis le fichier. À refaire à chaque utilisation.
  3. Ou l'installer dans le menu ScriptsCopie le fichier dans le dossier Presets/fr_FR/Scripts d'Illustrator (Mac : /Applications/Adobe Illustrator …/Presets/fr_FR/Scripts), puis redémarre Illustrator. Il apparaît dans Fichier › Scripts.

02Préparer le fichier

Le script lit le fichier Illustrator ouvert. Il faut :

Un jeu de variables par langue

Nommé avec le code de la langue (EN, FR, ES…). Panneau Variables › Capturer un jeu de données. Tous les jeux sont proposés, tu décoches ceux à ignorer.

Des variables liées aux objets

Texte dynamique…, avec les valeurs de chaque langue enregistrées dans son jeu.

Des artboards au nom unique

Ce nom sert au fichier exporté. Éviter les caractères / \ : * ? " < > |. Un code cmyk ou rgb déjà présent est aligné sur le mode du document.

Un mode colorimétrique cohérent

CMYK pour EPS et PDF, RGB pour PNG et SVG. Les formats qui ne correspondent pas au document sont grisés.

Contenu sur l'artboard

Ce qui est entièrement en dehors n'est pas exporté. Polices installées et images liées présentes.

Verrouillés et masqués

Les calques et objets verrouillés sont exportés (déverrouillés le temps de l'export, puis reverrouillés). Les masqués ne sont pas exportés.

La fenêtre du script contient un cadre « Vérifications » qui signale les problèmes avant l'export (noms en double, variables absentes, images liées introuvables…). Le bouton Prérequis… rappelle cette liste dans Illustrator.

03Utilisation

  1. Ouvre le fichier de logosLe document doit être actif dans Illustrator.
  2. Lance le scriptLa fenêtre d'options s'ouvre. Le cadre « Vérifications » signale ce qui cloche.
  3. Compose le nom des fichiersPréfixe, suffixe, code couleur, langue. L'exemple se met à jour en direct.
  4. Choisis les formatsSelon le mode du document : EPS et PDF (CMJN) ou PNG et SVG (RVB).
  5. Sélectionne langues et artboardsPlusieurs choix possibles ; « Tout » et « Aucun » pour aller vite.
  6. Choisis le dossierEt l'organisation des sous-dossiers.
  7. Lance un test d'abordCoche « Mode TEST » : une seule langue et un seul artboard sont exportés. Vérifie le fichier créé, puis relance sans le mode test.
  8. Clique « Exporter »Une barre de progression s'affiche. À la fin, un résumé indique les fichiers exportés, ignorés et en erreur, et le dossier s'ouvre.

Ton document d'origine n'est jamais enregistré ni modifié : chaque fichier est créé depuis une copie de son artboard.

04Options

Les réglages sont mémorisés d'une utilisation à l'autre (hors mode test et sélections). Le menu « Interface » de la fenêtre bascule entre français et anglais.

Nom des fichiers

Préfixe / Suffixe : texte ajouté avant et après le nom de l'artboard (par défaut pec_ en préfixe).

+ code couleur : ajoute _cmyk ou _rgb selon le mode du document, sans doubler un code déjà présent.

+ langue : ajoute _en, _fr… à la fin du nom, avant le suffixe. « Langue en minuscules » met EN en en.

Formats

EPS · PDF print : document CMJN. Le PDF peut avoir des repères de coupe.

PNG : document RVB. Fond transparent ou blanc, résolution 72, 144, 300 ou 600 ppi.

SVG : document RVB. Texte converti en contours (recommandé) ou conservé comme police SVG.

Dossier et organisation

Organisation : un dossier par langue · langue puis un sous-dossier par format · tout dans un seul dossier (la langue doit alors figurer dans le nom).

Ignorer les fichiers déjà présents : sinon les fichiers existants sont écrasés.

Ouvrir le dossier à la fin : affiche le dossier d'export une fois terminé.

Contenu des fichiers

Rogner au contenu : l'artboard de chaque fichier est ajusté aux limites du dessin.

Casser le lien des symboles : transforme les symboles en tracés simples dans les fichiers exportés. À tester : les variables ne pilotent pas toujours le contenu d'un symbole.

Mode TEST : exporte uniquement la première langue et le premier artboard sélectionnés.

05Résultat

Exemple avec le préfixe pec_, le code couleur et la langue activés, en organisation « langue puis format » :

export/
├── en/
│   ├── eps/  pec_neg_v_cmyk_en.eps
│   └── pdf/  pec_neg_v_cmyk_en.pdf
├── fr/
│   ├── eps/  pec_neg_v_cmyk_fr.eps
│   └── pdf/  pec_neg_v_cmyk_fr.pdf
└── export_log.txt

export_log.txt, écrit à la racine du dossier, liste chaque fichier créé, ignoré ou en erreur.

06Dépannage

« Aucun jeu de variables »
Le fichier n'a aucun dataset : crée-en un par langue dans le panneau Variables.
Le texte ne change pas d'une langue à l'autre
Aucune variable n'est liée aux objets : lie les textes dynamiques dans le panneau Variables.
Des fichiers s'écrasent
Noms d'artboards en double, ou « tout dans un dossier » sans langue dans le nom. Renomme ou ajoute la langue.
Artboard « vide » dans le journal
Aucun objet visible sur l'artboard : calque masqué ou contenu hors de l'artboard.
Images manquantes
Images liées introuvables : relie-les avant l'export.
Un format est grisé
EPS et PDF demandent un document CMJN, PNG et SVG un document RVB (Fichier › Mode colorimétrique du document).
