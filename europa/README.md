# Europa — maquette 3D de la lanterne

Maquette 3D de la lanterne de l'Europa building (fichier autonome, three.js via CDN). Le motif des bandes obliques est calculé dans le shader de l'enveloppe (dimensions réelles de chaque fenêtre) ; elles ne s'affichent que sur la face extérieure (`FLIP_SIDED`, car three.js dessine le double-face en deux passes). Clic sur un plateau = lanterne « développée » : 11 tranches (une par plateau) découpées par des plans de coupe horizontaux qui suivent leur décalage (`slices`, `updateExplode` dans `animate`) ; re-clic, vide ou Échap la referme. Les maillages d'origine servent hors animation. Reflets : `envMap` (RoomEnvironment) sur le vitrage et l'acier seulement ; roughness/metalness du verre et opacité de Fresnel sont modifiées dans le shader de l'enveloppe. Spots : tubes horizontaux par fenêtre (`ledYs`) + halo calculé dans le même shader. Salles : `roomsGroup` (`buildCouncilRoom` niveau 5, `buildSmallRoom` niveaux 1, 3, 7, 9).
